# EvoSnake 微信小游戏版

这是 H5 版的微信小游戏迁移目录。目标是手机正式版直接走微信小游戏运行时，而不是再依赖 Safari/微信 H5 的全屏与横屏权限。

## 当前实现

- `game.json` 固定 `landscape` 横屏。
- 全屏 Canvas，不依赖 HTML/CSS/DOM。
- 复用当前玩法核心：大地图、30 个 NPC、自主 AI、空间分区、大小蛇同等碰撞规则、死亡掉落。
- 10 阶整条身体进化。
- 16 种 Buff，全部使用沿身体运动的不同 Canvas 特效，不再使用头顶图标转圈。
- 30 套程序化皮肤。
- 玩家附近星光保底刷新，避免大地图空跑。
- 手机左下摇杆 + 右下按住冲刺。
- 相机按横屏窗口自适应 FOV。

## 在微信开发者工具中运行

1. 安装并打开微信开发者工具。
2. 选择 **小游戏** → **导入项目**。
3. 项目目录选择仓库里的 `minigame/`。
4. 当前 `project.config.json` 使用 `touristappid`，可以先做本地模拟器检查。
5. 要真机预览、上传体验版或发布，需要把 `appid` 换成你自己的 **微信小游戏 AppID**。

## 为什么用“小游戏”而不是普通“小程序页面”

这个项目是持续 60Hz 的 Canvas 实时游戏。微信小游戏运行时没有普通页面 DOM/导航结构的负担，更适合全屏横屏、触控、Canvas 高频渲染和后续性能优化。

## 目录

- `game.js`：小游戏入口。
- `game.json`：横屏配置。
- `src/config.js`：10 阶进化、16 Buff、30 皮肤、地图与 AI 参数。
- `src/engine.js`：蛇、食物、碰撞、AI、成长、Buff 机制。
- `src/spatial.js`：空间哈希网格。
- `src/render.js`：全屏 Canvas、皮肤、整身进化、Buff 特效、HUD/UI。
- `src/input.js`：触控摇杆、冲刺、菜单点击。
- `src/platform.js`：微信小游戏 API 适配。
- `src/main.js`：固定时间步主循环。

H5 版仍保留在仓库根目录，继续作为电脑试玩和快速调试版本。
