# EvoSnake 微信小游戏版

这是 H5 版的微信小游戏迁移目录。手机正式版直接走微信小游戏运行时，不依赖 Safari/微信 H5 的全屏与横屏权限。

## 当前实现

- `game.json` 固定 `landscape` 横屏，全屏 Canvas，不依赖 HTML/CSS/DOM。
- 15000×10500 大地图、30 个 NPC、自主 AI、空间分区、防拥堵与脱困。
- 大小蛇同等碰撞规则：任何蛇头撞到其他蛇身体都会死亡，不存在体型碾压或撞击免死。
- 10 阶整条身体进化、16 种 Buff、30 套程序化皮肤。
- Buff 使用沿身体运动的不同 Canvas 特效，不使用头顶图标转圈。
- 玩家附近星光保底刷新，避免大地图空跑。
- 左下摇杆 + 右下按住冲刺，相机按横屏窗口自适应 FOV。

## 下一阶段系统（已接入）

- **三条进化路线**：星潮灵体 / 苍穹龙脉 / 彗火猎手，在中期形成资源、操控追猎、机动抢点三种 Build 方向。
- **Buff 联动套装**：6 组组合效果。满足特定 Buff 组合后自动激活，例如潮汐引力、雷火彗星、暴食引擎、群星孵化。
- **稀有突变**：中后期触发三选一强力突变，本局永久生效；不提供碰撞免死。
- **地图热点生态**：星潮海、龙骨斗场、彗火裂隙、棱晶花园。各区域有不同资源密度和收益倾向，NPC 也会主动向热点迁移。
- **路线/联动/突变全身特效**：只使用身体光纹、流线、粒子和环形能量，不增加头顶贴图。

## 在微信开发者工具中运行

1. 安装并打开微信开发者工具。
2. 选择 **小游戏** → **导入项目**。
3. 项目目录选择仓库里的 `minigame/`。
4. `project.config.json` 已配置当前小游戏 AppID，可直接用对应管理员/开发者微信号预览、真机调试与上传。
5. 后续代码更新建议用 Git / GitHub Desktop 拉取，不需要反复下载 ZIP 和重新导入项目。

## 目录

- `game.js`：小游戏入口。
- `game.json`：横屏配置。
- `src/config.js`：10 阶进化、16 Buff、30 皮肤、地图与 AI 参数。
- `src/engine.js`：蛇、食物、碰撞、AI、成长、Buff 机制。
- `src/advanced.js`：进化路线、Buff 联动、稀有突变、地图热点与高级视觉层。
- `src/spatial.js`：空间哈希网格。
- `src/render.js`：全屏 Canvas、皮肤、整身进化、Buff 特效、HUD/UI。
- `src/input.js`：触控摇杆、冲刺、菜单点击。
- `src/platform.js`：微信小游戏 API 适配。
- `src/main.js`：固定时间步主循环与高级系统安装。

H5 版仍保留在仓库根目录，作为电脑试玩和快速调试版本。
